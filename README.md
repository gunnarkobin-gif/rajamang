# Rajamängu skoorikaart

Golfi rajamängu (match play) skoorikaart 18 rajale. Üks staatiline HTML-fail, töötab telefonis ka ilma levita.

- Sinu ja kuni kolme kaasmängija löögid raja kaupa
- Mängija kaupa löögiedu (+1 lööki rajal → netoskoor)
- Vormid: eraldi matšid · kõik koos sinu vastu (parim skoor) · kahesed tiimid parima skooriga · kahesed tiimid summaga
- Jooksev seis (2 üleval / viigis / dormie / „Võit 3&2“), märgistus kelle skoor tiimist arvesse läks
- Skoor salvestub telefoni brauserisse, ringi keskel äpi sulgemine ei kaota seisu

## Kasutamine

Ava `index.html` GitHub Pages aadressilt ja lisa Safaris avalehele (Share → Add to Home Screen).

Failid: `index.html` (kogu äpp), `sw.js` + `manifest.webmanifest` (avalehe ikoon ja offline), ikoonid.
